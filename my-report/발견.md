> 오늘은 "여기가 낮다 · 이만큼 크다"까지다. **왜 그런가는 내일, 무엇을 할 것인가는 모레다.**
> 이 문서에 원인과 제안을 쓰지 않는다.

**재현 경로** — 읽는 사람이 다시 세어볼 수 있도록:

```
그레인    GRN 1건 (nunique)
제출      GRASNotices 전체 행                      -> 1,336건
종결      GRASNotices.cat != "Pending"             -> 1,301건
결과_성공  GRASNotices.cat == "no_questions"        -> 1,056건
축        GRASNotices.bio (숙주식별 / 미분류) · GRASNotices.country (미국 / 해외 / 미상)
비중 분모  종결 도달 1,301건  (발견 2만 전체 손실 280건)
```

⚠ 축 분해는 `metrics.funnel_by()` 가 낸 값이 **아니다.** 그 함수는 이벤트 로그를 요구하는데
어댑터가 없다(미정). 위 조건으로 스냅샷에서 직접 센 값이고, `notes/퍼널실측_2026-08-29.md` §4 와 일치한다.
**"앱에서 조회했다"고 쓰지 않는다.**

## 발견 4 — 국가로는 갈리지 않는다

| 값 | 미국 **80.35%** (503 / 626) |
|---|---|
| 비교 대상 | 해외 **81.85%** (550 / 672) |
| 격차 | **1.50%p** — `config.MIN_GAP` 5%p 미달 |
| 비중 | 미국이 **종결 도달 1,301건의 48.12%** (보인 칸 둘 합계 1,298건 = 99.77%) |
| 표본 | 미국 626건 (한 건 0.16%p) · 해외 672건 (한 건 0.15%p) · **9건**이면 격차 소멸 |
| 크기 | 격차 x 비중 = **0.72** · 절대 **9건** (미국 626건 x 1.50%p) |
| 데이터 출처 | **실측 GRASNotices** |

- **비중은 큰데 격차가 작은 칸**이다. 절반에 가까운 덩어리인데 갈리지 않는다.
- 한 건 흔들림(0.16%p)보다 격차(1.50%p)가 크므로 표본 우연은 아니다. 다만 **9건이면 사라지는 크기**다.
- 「못 쓰는 숫자」가 아니라 **「찾았는데 없던 것」**이다. 값을 적는다.

## 크기 요약

| 발견 | 격차 | 비중 (낮은 쪽) | 격차 x 비중 | 절대 건수 |
|---|---:|---:|---:|---:|
| 1 숙주식별 여부 x 성공률 | 13.69%p | 73.64% (미분류) | 10.08 | 131건 |
| 2 병목 구간 (종결 -> 결과) | 16.21%p | 87.50% (전체 손실 중) | 14.18 | 245건 |
| 3 숙주식별 여부 x 자진철회율 | 12.01%p | 73.64% (미분류) | 8.84 | 115건 |
| 4 국가 x 성공률 | 1.50%p | 48.12% (미국) | 0.72 | 9건 |

- 비중 분모: 1·3·4 = 종결 도달 1,301건 / 2 = 전체 손실 280건
- 절대 건수 = 그 칸의 도달 건수 x 격차
- ⚠ 발견 2는 **구간끼리** 비교라 1·3·4(칸끼리 비교)와 같은 자로 재면 안 된다.
- ⚠ 비중을 낮은 쪽이 아니라 높은 쪽으로 잡으면 크기가 달라진다. 발견 1을 숙주식별(26.36%)로
  잡으면 크기 3.61 · 47건으로 **2.8배 작아진다.** 어느 칸을 문제로 볼 것인가가 크기를 정한다.

### 순서를 매기지 않는다 — 구조로 둔다 (2026-09-08 결정)

네 발견에 1위~4위를 붙이지 않았다. 크기 x 비중 값이 큰 순서(2 > 1 > 3 > 4)로 줄을 세우면
**성격이 다른 것을 같은 자로 잰 것**이 된다 — 발견 2는 구간끼리, 1·3·4는 칸끼리 비교다.

대신 **좁혀 들어가는 구조**로 읽는다:

```
발견 2   어느 구간인가        손실 280건 중 245건(87.50%)이 종결 -> 결과 한 구간
  |
  +-- 발견 1   그 구간의 어느 칸인가     미분류(도달의 73.64%)에서 131건
  +-- 발견 3   그 칸이 어떻게 빠지는가   같은 칸의 자진철회에서 115건
  |
발견 4   거기가 아닌 곳        관측자가 못 바꾸는 축으로는 9건 — 갈리지 않는다
```

- 발견 2가 **구간을 좁히고**, 1·3이 **그 안의 칸을 좁힌다.** 4는 그 축이 아님을 확인한다.
- 셋이 같은 곳을 가리킨다. 순위가 아니라 **한 줄기**다.
- ⚠ 1과 3의 건수(131 · 115)를 더하지 않는다. 같은 칸을 다른 각도로 센 것이다.
- ⚠ 이 구조는 **어디를 볼 것인가**까지다. **왜 그런가는 내일이다.**
